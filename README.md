# 天规 · Celestial Law

黑暗中式修仙与规则怪谈题材的动作肉鸽原型。守规求生，借规杀敌，炼规成仙。

## 完整主线 · 无名之人 0.6

打开 [campaign.html](campaign.html)：报丧村 → 回首祠 → 倒悬寺 → 无名城 → 登天台。一局包含四章各六个节点，以及终审合卷、整备、三阶段终战。24 项技能（16 常规、8 桥接）共用施印、推击、纸人、裁决与灯烬事件；最多装备 8 项、其中桥接 2 项，满槽可替换或把奖励化作香火。

镜律以本体与镜影的红线两侧位置判罚，F 拖镜架、Q 推镜影；名律按点名牌归责，F 转移，北侧登记台可撤销或登记。每章可以护送一位证人，成功证言跨局保存。

三个结局都有实际战斗目标：继律接灯守四印三轮；断律按钟、目、镜、名逐柱退罚，四柱毁后击败执衡；共律需要四证齐备，每轮回到中央归责，保护三轮公议。终审修订只影响选中的律种。通关后重开以“旧案重演”叙事呈现。

WASD 移动，鼠标控制朝向，有敌人时自动发射追踪飞剑（纸人剑、追击剑同样追踪；鼠标仍控制朝向和纸人落点），Q 震步，E 纸人，空格闪避，Shift 闭目（仅免目律），R 改律，F 场景互动，P 暂停。无需安装依赖，可直接离线打开；本地服务器预览使用 `python3 -m http.server 8765 --bind 127.0.0.1`。0.5 安全节点存档可继续，结算后的旧局需重新起行。正常模式不提供测试跳关按钮。

[实现范围、运行测试与验证限制](CAMPAIGN_VALIDATION.md)。[完整策划方案](plan.html)保留为原始设计参考，当前实现进度以此文档为准。旧版 0.3、独立试炼 0.4 保持可用。

## 构筑迭代 · 参考《暖雪》

借鉴[官方介绍中的宗派、圣物多效果与神兵联动](https://store.steampowered.com/app/1296830/_Warm_Snow/?l=schinese)，本次先实现“法门定打法 → 奖励补组件 → 组合改变效果”的结构，没有复制原作技能或加入圣物四槽系统。

- 新局从剑印、纸阵、震雷三门选择，均有明确收益与代价，不额外占技能槽。旧局保留原构筑，不强加法门。
- 剑律循环：篆剑诀 + 借律成剑 + 断案诀，追击剑补短印，接入后续裁决。
- 百纸送葬：留影步 + 纸上行军 + 焚身经，纸人推击同时施印，衔接追雷或借尸还剑。
- 震雷回流：追雷印 + 回风诀 + 定身敕，定身目标中雷后产生不会继续连锁的规则溅射。
- 奖励优先提供现有组合缺件，再给延伸与跨流候选；随机种子控制同分候选。每局两次封存，将候选移出本局池并重新生成奖励。跳过、重抽、满槽替换仍保留。
- 侧栏与案卷显示组合进度、缺件和实际效果；替换所需技能会立即失去成型效果。法门不限制其他技能搭配。

验证：`node tests/campaign-buildcraft.test.cjs`；三法门各三个命签的完整流程模拟均获胜，记录在 `tests/campaign-buildcraft-simulation-results.json`。这只证明可达性，尚未替代真人平衡测试。

## 声音更新

原创 Web Audio 合成声景：五声音阶拨弦与低音氛围、战斗鼓点、首领战加速节奏；飞剑、命中、受击、闪避、震步、纸人、天规预警、钟声、雷击和结算音效。不是录制的真实民族乐器。

点击页面或按键后启用音频。右上角「声音设置」支持音乐/音效独立音量和静音，自动保存。暂停、帮助页及切出窗口时静音。音频不消耗玩法随机数，浏览器不支持 Web Audio 时可继续无声游玩；没有外部音频请求。

## 本地运行

直接用桌面浏览器打开 `index.html`。无需安装依赖、构建步骤、账号或联网。

请保留完整仓库结构，包括 `art.js`、`audio.js` 与 `assets/` 素材目录。也可以使用任意静态 HTTP 服务器运行仓库根目录。

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD / 方向键 |
| 自动瞄准飞剑 | 持按 J / 鼠标左键 |
| 震步推敌 | Q |
| 纸人代罚 | E |
| 闪避 | 空格 |
| 暂停 | P / Esc |

钟响前停止移动，或用纸人代罚；钟响前把妖物推开，可让天雷替你杀敌。闪避不能免除天规惩罚。

## Cloudflare Pages 部署

连接此 GitHub 仓库，使用以下配置：

| 字段 | 值 |
| --- | --- |
| Project name | `celestial-law` |
| Production branch | `main` |
| Framework preset | `None` |
| Build command | `exit 0` |
| Build output directory | `.` |
| Root directory | 留空，使用仓库根目录 |
| Environment variables | 无需添加 |

点击 **Save and Deploy**。以 Cloudflare 返回的生产地址为准。配置 Git 集成后，生产分支的新提交可触发后续部署。

[Cloudflare 静态 HTML 部署文档](https://developers.cloudflare.com/pages/framework-guides/deploy-anything/)

## 文件说明

- `campaign.html` / `campaign-core.js` / `campaign.js` / `campaign.css`：完整主线入口、纯战斗模拟、界面与绘制、样式。
- `index.html`：旧版游戏入口与主线入口链接。
- `game.js`：游戏逻辑与 Canvas 绘制。
- `style.css`：界面样式。
- `audio.js`：原创程序音乐、音效及声音设置。
- `art.js`：美术素材加载、角色与场景渲染；加载失败时回退原始图形。
- `assets/`：场景、角色图集、标题画与提示词记录。
- `plan.html`：游戏设计、内容范围、开发路线和验收计划。
- `verification.txt`：测试记录及验证限制。
- `DEPLOYMENT.txt`：部署配置速查。

局外解锁保存在浏览器 localStorage。清除站点数据会清除解锁；不同浏览器、不同域名及本地文件入口的存档不共享。

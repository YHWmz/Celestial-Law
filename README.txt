天规：报丧村 · 声景版本 v0.3

启动：双击 index.html，用桌面版 Chrome / Edge / Safari 打开。
详细计划：打开 plan.html（可通过浏览器打印为 PDF）。

操作：WASD / 方向键移动；持按 J 或鼠标左键自动瞄准攻击；
Q 震步推敌；E 纸人代罚；空格闪避；P / Esc 暂停。

目标：经过六处路线，击败报丧人与所有随从。
钟响前停止移动，或用纸人代罚；Q 推动妖物，让天规替你杀敌。
战后选择功法，中途有精英、事件、商店和休整路线。

本版本为玩法验证原型，不是最终美术和数值。
支持键盘鼠标；未实现移动端触控、局内断点续玩。
局外解锁保存在本机浏览器。更换浏览器/地址不会共享存档。
请保留完整目录，包含 art.js、audio.js 与 assets/ 图片素材。
无安装步骤，无外部网络资源，无账号或联网要求。

命签：留空随机；填写相同命签、选相同契约与路径，可复现内容随机序列。
命签不记录玩家操作，因此不能复现完整战斗过程。

源代码：game.js（玩法与渲染）、style.css（界面）、index.html（入口）。
测试结果见 verification.txt。

声音：首次点击或按键后启用；右上角声音设置调整音乐/音效。暂停与切出窗口静音。

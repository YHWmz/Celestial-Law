新的主线命题：你最初想让一个人免受天罚，最终必须决定，谁有权制定所有人的规矩。战斗中的诱敌、替身、转罚和改律，分别对应故事中的证言、牺牲、归责和立法。

本次是策划更新，不是玩法发布。游戏仍为报丧村 0.3 + 回首祠 0.4。本文从第 03 节起的剧情、章节、技能和数值均为目标设计，尚未实现或验证。策划版本 0.5 不代表游戏版本 0.5。用户已要求展开长程设计，因此不再沿用旧验证记录中“等待反馈后才能写完整拓展方案”的文档限制；真人试玩仍是制作决策依据。

03 / 长程主线：无名之人，重审天规

开场与世界因果

七日前，妹妹阿照被选作“天灯”，姓名从家谱和邻人的记忆里消失。你只记得她系在腕上的红绳。今夜，纸扎铺送来一只用她笔迹写成的纸人：“天亮之前，别让他们把最后一笔写完。”你带它进入报丧村，寻找天灯册的四枚印记，准备登天救人。

天道曾以四条临时戒律封住灾劫：止住夜行、隔开目光、锁住倒影、核定姓名。灾劫已过，掌律者却把临时禁令变成永久统治。所有无人认领的惩罚，都由天灯承担。阿照既是眼下的承罚人，也是天道重写当天的锚。

玩家曾是执笔小吏，亲手写过“无主之罚，由无名者承受”。阿照为了救你，抹掉你的登记姓名，使你逃过定名处刑；代价是她被天灯册选中。无名只避开依赖登记姓名的追索，不免疫针对生者、位置或行为的天规，因此不与玩法冲突。

主要人物：每个人都承担一个系统功能

人物表面职责与立场关系发展与游戏作用
阿照 / 天灯中的妹妹纸人传来的断续声音；想活着回来，但拒绝再找一个人替她每章恢复一段记忆。纸人是她制作的空壳，不是她的生命；战斗中损毁不伤害阿照。终局明确表达自己的选择。
素娘 / 纸扎匠无名观经营纸铺，相信任何人都不该只是代价教会替身、提供安全试验场；得知旧案后追问玩家是否还把别人当工具。
闻烛 / 师父无名观守灯人，主张由一个强者承罚以保众生保留部分旧档但隐瞒执笔者身份；支持“继律”结局，不能代玩家作决定。
执衡 / 掌律者四章间留下批示，终章亲自审判；相信取消归责就会重演灾难论点有现实依据：解除禁令确实需要新的保护措施。不是单纯追求力量的最终恶人。

每章真相必须由一件行动证明

阶段玩家当时的目标行动获得的事实下一步动力
一 · 报丧村夺回天灯转运簿，找妹妹去向让报丧人的灵牌进入钟裁，发现执行者也被自己的名册约束；村民曾为夜行禁令签名簿上写着：阿照主动去了回首祠；“被掳走”的理解开始动摇
二 · 回首祠找到目击证言改动视线判词后，石像背面的证词显现：阿照是在替一个被抹名的人上灯她救的是谁？去倒悬寺寻找那个人遗失的影子
三 · 倒悬寺取回自己的过去通过镜面把受罚者与签字者的影子对齐，看见玩家写下转罚条款营救变成偿还旧债；必须找到废止条款的方法
四 · 无名城取得登天资格与原始律本把从未被记录的居民登记为证人，证明“无名”不等于“无人”；看到阿照原本的名字发现存在分担且可撤回的契约，决定如何结束天灯制度
终 · 登天台击败执衡并救出阿照把四章取得的证据用于终审，最后实际执行继律、断律或共律通过最后一次战斗行为兑现结局

轮回怎样服务长故事

每次玩家死亡或终审失败，天灯都会把有登记的世界退回当夜。无名观位于被划掉的簿页上，素娘、闻烛和封入纸档的证据得以保留。首领再次出现是同一夜的重审；玩家携带的案卷让重审目标、对话和可选判词变化。纸人声音在每个新证据后变化，避免重复装作第一次认识。

采用可单次通关的主线 + 跨局累积的关系与旁证。首次完整通关就能抵达终章并选择继律或断律；满足全部共律条件的熟练玩家也可首局达成共律。不要求先失败或反复打指定次数。新证据实时保存；对话按“终局决定 ＞ 新关键证据 ＞ 人物回应 ＞ 氛围闲谈”排队，每次返观最多两个主要话题。

章内死亡清空本局功法、香火、改律和路线；案卷、见闻、已解锁起始形态及关系阶段保留。主线每章的转折房固定出现；错过支线的补救路径会在案卷中写明。单局 35—45 分钟、完整叙事体验 6—10 小时仅是内容预算假设，须用实际制作速度和试玩修订。

04 / 统一底层：同一套裁决语言，四种章节考题

一次裁决 = 在指定时机，对范围内符合身份与行为条件的对象，按归责关系执行结果。

所有章节都使用位置、朝向、身份、印记、替身、裁决六个概念。新章只引入一个主要判定维度；普通房间同时最多一条天规，后期精英和首领最多两条。旧章规则只在明确标注的复习房出现，不把全部规则永久叠在身上。

基础动作 / 状态统一定义（目标版）跨章价值
飞剑 / J 或左键鼠标朝向出剑；提供可独立通关的直接伤害，可由功法施印。提供可选辅助瞄准击中、施印、斩杀、触发场景机关

替身归责每次裁决至多转移一次；空纸人默认无身份，须功法或登记机关赋予被追责资格解决“谁被罚”，不改变“是否犯规”的判定

新判定的边界必须先说清

镜律使用房间明确绘制的单一镜轴，倒影位置由本体关于镜轴的投影确定；镜台移动时投影同步更新。身体中心与影子中心距朱线小于 12 单位视为压线，两种镜律都免罚，形成窄而可见的安全带；离开安全带才比较两侧。普通推击移动本体，首领可动镜身则暂时改变关联影位，场地连线显示该特例的剩余时间。

名律先锁定本次被唱出的牌号，裁决时读取该牌当前归责者；移牌只改变归责，不修改承担者的活物身份。每个角色同一时刻只有一张有效归责牌，复制纸人不复制牌；玩家通过 F 将已锁定名牌移出登记台或移交可接受该牌的场景承罚座，规则 UI 同步更新承担者。默认只提供一次转移，不允许名牌在多人之间无限反弹。

改律：每章一次机会，预览后才确认

每章入口获得一笔朱墨；不能囤积，离章清空。R 暂停并展示该章两种经过设计的修订，确认后本章持续有效；下一章恢复当地原律。终章也给一笔，但只能修改正在执行的一条已学过的律。原试炼的“一局一次”在完整流程中调整为“一章一次”，独立 0.4 试炼维持原样。

候选改写只改对象或条件，结果代价随选项明示；例如“生者→妖物”使玩家免罚，但对妖物裁决伤害降为原值约 65%。剧情中的重订天规是终局行为，不由战斗中用了几次 R 自动决定。强力构筑不触发隐藏惩罚或偷偷提高敌人血量。

读得懂、验得出

地面用形状区分判定：扇区为视线、虚线为诱敌、实线为归责；不要只靠颜色。锁定预警至少 1.2 秒。战后显示简短因果：“纸人诱敌 → 妖物面神 → 第三次裁决 → 连坐击杀”。战斗日志可暂停查看，但不把完整事件树常驻屏幕。训练场可放置一个妖物、任意已解锁功法并逐步触发一次裁决。

关卡约束与防止构筑失效

  • 每个规则房必须用基础飞剑、Q、E 和场景交互完成；没有指定功法也至少存在一种守规打法、一种诱敌打法。
  • 首领不能全免疫律印、规则伤害或全部位移接口；重型本体以可动灵牌/镜身/名牌提供等价接口。
  • 镜律与名律关键交互使用统一 F 键，进入房间前教学；完成一次交互目标约 0.3 秒，允许即时躲避取消。无名城入口用可见的临时客籍号给玩家建立章内归责，所以“没有真实姓名”不能免掉本章玩法。

触发顺序与组合边界

顺序固定：预警/朝向 → 身份与犯规快照 → 偷名转罚 → 纸人代罚 → 印记增幅 → 本次伤害 → 击杀/资源 → 二级效果。转罚不再次转罚；同一伤害只结算一次。飞剑是否“主动”、位移由谁造成、规则是否来自环境都保留来源，避免写成“所有伤害都触发所有技能”。

根事件带唯一编号。追击剑、连坐、同罪复制都是终端子事件，不再产生同类子事件；复制可造成击杀但不触发连坐或余烬。追雷与断案各自可成为根规则事件，并受各自冷却限制。代天行罚消费前的律印快照可供借律成剑读取，但不能再次消费。若偷名和替身同时可用，优先转给名契目标，纸人保留。

强力组合应允许明显压倒普通敌人；限制针对无限循环、无输入全自动和不可读画面，不以临时“此首领免疫此流派”抵消玩家投入。伤害加成同类相加，转换层有限相乘；先记录极端构筑再调参。

一条构筑在四章中如何改变用法

以“篆剑诀 + 三叠浪 + 追雷印 + 借尸还剑”为例：报丧村用第三剑把停步敌人推入钟罚；回首祠先施印，纸人吸引目标转头，再推入扇区；倒悬寺用第三剑改变妖物或镜身位置，让本体与倒影异侧；无名城用纸阵压制笔吏，自己趁间隙交换名牌。技能不换，判断与走位在变。对不受当地规则影响的窗口，追雷与纸人飞剑仍能输出。

奖励节奏与抽不到的补救

  • 起始选一项普通功法，并预览两种可能连接。四章的分岔战与综合战各给一次三选一，共 9 次获得机会；上限 8 项，多出的用于替换、升级或换香火。章首领提供叙事印记和一次功法升级，不另开第二个遗物系统。
  • 每次奖励目标结构：“一项能接当前构筑、一项补当前弱点、一项探索新方向”。按技能真实产物/消费者筛选，而不只是相同颜色。池不足时补独立可用普通项，不生成空选项。
  • 普通项全部在全局池；桥接项满足任一相关入口后才入池，UI 展示完整条件。桥接槽已满时，奖励明确标示替换，不能悄悄丢失旧效果。
  • 连续两次奖励没有拿到可衔接项，下一次至少提供一个有效连接。第二章整备可从已获得的两个功能标签中定向抽一次普通连接件；不保证指定稀有桥。
  • 每局 2 次免费重抽；每章一次免费换下功法；替换时展示丢失的触发链。不能通过反复进入商店刷新库存。
  • 局内只有香火一种货币；朱墨是章内次数，余烬是战斗资源。商店测试起点：治疗 25、升级 40、定向普通件 45、随机桥接件 65；每章普通收入目标 55—75，使治疗与成型竞争。精英额外收入 20，附风险预告。

跨局发展

局外保留见闻、人物和起始形态；不永久堆攻击与生命。初始就开放足够完整的普通与桥接池，不能靠数十小时解锁才能形成第一套联动。新形态改变 Q/E 的配置或起始功法，但仍能访问全部功能；建议首发仅三种起始配置，不同时做三种武器动作系统。

四章各完成一宗自愿证言支线；证据可跨局累计，当局在第四章登记共约		四名自愿证人的印记形成可撤回的共约；依次把无主裁决归还执衡自己的名牌，并保护证印完成三轮公议。不是把罚分摊给平民，也不消耗纸人冒充居民同意。废除无主转罚，封印改由公开、有限、可退出的守护职责维持；阿照与玩家都保留姓名。四地各有一段履行共同责任的尾声，不声称从此没有灾难。

共律支线每章固定可选择，不随机稀有出现；目标失败可下局重试，不锁死存档。前三章支线完成标记永久保存；第四章登记是汇总已得证据的确认步骤，第四章支线完成后立即可做。玩家若不满足条件，案卷准确列出缺少哪个证人及所在节点，不用“隐藏好感度”暗门槛。

阶段 / 交付具体范围进入下一阶段的条件

11 / 验收：证明故事、关卡、构筑真的连在一起

以下都是未来测试目标，不是已取得的结果。先邀请 8—12 位未读设计文档的试玩者完成 P1；用录像（经同意）、本地日志及访谈交叉判断，小样本用于发现问题，不推算商业留存。

问题观察方式 / 初始通过门槛失败后优先改什么
玩家知道自己为何前进吗？第一章后至少 8/10 能说出救谁、为何去祠堂；第二章后至少 7/10 能复述阿照主动承罚的疑问。减少名词与旁支；把转折放回必须参与的行动，不加更多说明书。
规则能解释且能重复吗？首次规则击杀后，多数人可说清位置/行为/裁决关系，并在下一场主动复现。预警与因果提示、敌人数、教学房布局。
两章是同一款游戏的不同考题吗？至少三套构筑跨章通关；每套在两章出现不同站位/诱敌/时机选择。改房间与敌人行为；不简单换颜色或强制删掉玩家功法。
技能是在互相供给吗？日志能观察到至少三种“入口→转换→收益”链；选完桥接技能后玩家确实调整操作。优先增加独立可用连接点，减少纯数值奖励与只服务单章的功法。
玩家为何重开？至少一半试玩者自发或在中性询问后愿意再试，并能说出另一条组合或改律计划；区别礼貌评价。调整奖励分岔与可试验空间；不以强制多周目剧情延长寿命。
有没有唯一固定解？比较持久闭目、纸人固定站位、主动借律、直接剑击；观察完成率、时长与操作密度。如果安全静置策略同时最快且最稳，加入可预测的敌人压力或调整机会成本。
首领是否压制某个流派？所有 6 条样例构筑在各章至少完成一次普通操作测试；再测试无桥接功法的基础构筑。补操控接口、降低无交互护体覆盖率，不靠指定掉落开锁。

必要的机制与流程测试

  • 四种判定、两种修订、敌我共享边界、镜身与名牌归责、首领关联物、闭目适用范围。
  • 24 项单件及 8 项桥接的有/无输入条件；所有声明的组合链、冲突、内置冷却、召唤上限及终端不递归。
  • 奖励无重复、连续补救、桥接槽替换、商店库存、重抽、存档恢复和独立入口回归。
  • 首次通关、任意章死亡、支线失败补救、单局共律与跨局共律、三个结局、结局后继续挑战。
  • 手工验证每个双规则房的安全路径与改律后状态；大量种子检查只能发现部分问题，不能证明所有关卡有趣。

每个新技能须有至少两条跨功能连接，或证明它承担必要的独立输出/生存角色；每章须有一处无需文本也能看出故事原因的机制；每个结局须复用此前学过的操作，而非临时增加全新小游戏。
